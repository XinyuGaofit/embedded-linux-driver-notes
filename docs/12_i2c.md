# 12. I2C

## 分层

```text
I2C sensor driver
       ↓
     I2C Core
       ↓
I2C adapter/controller driver
       ↓
SoC I2C controller
       ↓
SCL / SDA
       ↓
sensor
```

## 设备树

```dts
&i2c1 {
    status = "okay";

    sensor@68 {
        compatible = "demo,my-sensor";
        reg = <0x68>;
    };
};
```

这里 `reg=<0x68>` 表示 I2C slave address。

## i2c_driver

```c
static const struct of_device_id my_of_match[] = {
    { .compatible = "demo,my-sensor" },
    { }
};

static struct i2c_driver my_driver = {
    .driver = {
        .name = "my_sensor",
        .of_match_table = my_of_match,
    },
    .probe = my_probe,
    .remove = my_remove,
};
```

注册：

```c
i2c_add_driver(&my_driver);
```

注销：

```c
i2c_del_driver(&my_driver);
```

## SMBus helper

```c
ret = i2c_smbus_read_byte_data(client, reg);
ret = i2c_smbus_write_byte_data(client, reg, value);
```

|API|返回|
|---|---|
|read|>=0 数据；<0 errno|
|write|0/负errno|

## i2c_transfer

```c
u8 reg = 0x3B;
u8 buf[6];

struct i2c_msg msgs[2] = {
    {
        .addr = client->addr,
        .flags = 0,
        .len = 1,
        .buf = &reg,
    },
    {
        .addr = client->addr,
        .flags = I2C_M_RD,
        .len = sizeof(buf),
        .buf = buf,
    },
};

ret = i2c_transfer(client->adapter, msgs, 2);
if (ret != 2)
    return ret < 0 ? ret : -EIO;
```

成功通常返回完成的 message 数，不是固定 0。

## 私有数据


## 上下文

同步 I2C 传输可能睡眠。

不要在 hard IRQ 中直接 `i2c_transfer()`。

常见做法：

```text
hard IRQ
  ↓
threaded IRQ / workqueue
  ↓
I2C transaction
```
