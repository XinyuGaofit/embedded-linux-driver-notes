# 16. V4L2

V4L2 是 Linux 视频设备框架，不是某一种摄像头协议。

USB Camera：

```text
application
   ↓
V4L2 API
   ↓
video_device / vb2
   ↓
uvcvideo
   ↓
USB Core
   ↓
USB controller
   ↓
camera
```

MIPI CSI 摄像头则是另一套底层驱动，但用户态仍可能看到 `/dev/videoX`。

## 用户态常见接口

```c
open("/dev/video0", ...);

ioctl(fd, VIDIOC_QUERYCAP, ...);
ioctl(fd, VIDIOC_S_FMT, ...);
ioctl(fd, VIDIOC_REQBUFS, ...);

mmap(...);

ioctl(fd, VIDIOC_QBUF, ...);
ioctl(fd, VIDIOC_STREAMON, ...);

poll(...);

ioctl(fd, VIDIOC_DQBUF, ...);
```

这些属于 V4L2 API，不是 UVC USB 协议。

## 核心对象

```text
v4l2_device
video_device
v4l2_subdev
vb2_queue
v4l2_file_operations
v4l2_ioctl_ops
```

`video_device` 代表一个 video node。

## v4l2_device_register

```c
ret = v4l2_device_register(dev, &d->v4l2_dev);
```

## video_device

常见字段：

```c
vdev.name
vdev.fops
vdev.ioctl_ops
vdev.v4l2_dev
vdev.queue
vdev.lock
```

注册：

```c
video_register_device(&vdev, VFL_TYPE_VIDEO, -1);
```

注销：

```c
video_unregister_device(&vdev);
```

## V4L2 fops

示意：

```c
static const struct v4l2_file_operations my_fops = {
    .owner = THIS_MODULE,
    .open = v4l2_fh_open,
    .release = vb2_fop_release,
    .poll = vb2_fop_poll,
    .mmap = vb2_fop_mmap,
    .read = vb2_fop_read,
    .unlocked_ioctl = video_ioctl2,
};
```

具体 `VIDIOC_*` 行为通常通过：

```c
struct v4l2_ioctl_ops
```

配置。

## videobuf2

`vb2` 负责大量视频 buffer queue 工作：

```text
REQBUFS
QBUF
DQBUF
mmap
poll
stream state
```

核心：

```c
struct vb2_queue queue;
```

配置字段后：

```c
vb2_queue_init(&queue);
```

常见字段：

```text
type
io_modes
drv_priv
ops
mem_ops
buf_struct_size
timestamp_flags
lock
dev
```

## 学习主线

```text
video_device 注册
      ↓
fops / ioctl_ops
      ↓
vb2_queue
      ↓
buffer enqueue
      ↓
硬件 / DMA
      ↓
frame done
      ↓
vb2_buffer_done
      ↓
DQBUF / poll
```

V4L2 解决统一接口，具体 camera driver 负责 sensor、CSI/USB、DMA、frame done 等硬件细节。
